# Agrinova
Gamified platform of farming


🌱 Farming Simulation Web Game

A simple farming simulation game built as a web application.
Players can experience the real farming cycle — from soil selection to selling crops in the market.

🎮 Features

Soil selection

Crop selection

Ploughing (cow cart → tractor upgrade)

Seeding

Irrigation (drip, sprinkler, flood)

Seasonal changes (summer, winter, monsoon → crop filtering)

Fertilizers & soil nutrition

Crop harvesting

Market rate system for selling crops

Extra Features

Weeding (slow growth if ignored)

Pest control (use pesticides/organic methods)

Weather events (rain, drought → affect crops)

Storage & marketing (dynamic crop prices)

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

(Optional) React.js + Tailwind CSS for better UI

Future Backend: Node.js, Express, Firebase/MongoDB

🚀 Game Flow

Choose soil type

Select crops (filtered by soil & season)

Plough → seed → irrigate

Manage fertilizers, weeds & pests

Grow & harvest crops

Sell crops in market at changing rates
